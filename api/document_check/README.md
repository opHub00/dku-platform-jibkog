# 청약 서류 점검

`base_checklist.json`에는 여러 공고가 재사용하는 서류 유형과 항목을 둡니다. `noticed_checklist.json`에서 공고의 공통 필수 서류를 먼저 적용하고, 그 위에 선택한 제출 유형의 서류와 항목을 추가하거나 제거합니다. 유형을 지정해야 하는 공고의 경우 선택 전까지 결과는 `rules_unavailable`입니다.

서명·직인은 PDF의 텍스트 표기를 확인합니다. 실물 확인, 위변조 검증과 최종 청약 자격 확인은 별도입니다.

## 실행

프로젝트 폴더에서 실행합니다. 필수 서류와 각 서류의 필수 항목이 전부 확인되면 종료 코드 0, 보완이 필요하면 1입니다. 공고를 지정하지 않는 실행은 아래 가상 A17 예시 폴더에만 적용되며 결과에 `notice.demo`가 표시됩니다. 다른 폴더에서는 공고 번호 또는 안내 링크와 제출 유형을 지정하세요.

```powershell
python -m pip install pypdf
python api/document_check/cheking_document.py batch api/document_check/test_document/complete
python api/document_check/cheking_document.py batch api/document_check/test_document/needs_review
```

Gemini 모드는 현재 터미널에 `GEMINI_API_KEY`를 설정하고 `--ai`를 붙여 실행합니다. 추출한 PDF 텍스트를 Google로 전송하므로 가상 서류로 테스트하세요. Python은 Gemini가 찾은 근거를 원문과 대조합니다. 스캔본은 수동 확인으로 표시합니다. Gemini 분석은 PDF 한 장씩 진행합니다. 일시 오류가 발생하면 같은 모델에서 첫 호출을 포함해 최대 세 번 시도한 뒤 다음 모델로 넘어갑니다. 모델 순환은 서류마다 최대 다섯 바퀴이며, 바퀴 사이에는 5·10·15·20초를 기다립니다. 인증 오류처럼 재시도로 해결하기 어려운 오류가 발생한 모델은 해당 서류의 이후 시도에서 제외합니다. 모든 시도가 HTTP 503이면 해당 서류에 서버 혼잡과 재검사 안내를 남기고, 나머지 서류 검사는 이어갑니다.

## 공개 서식 PDF 검사

텍스트가 포함된 LH 개인정보 동의서, 금융정보 동의서, 자산보유사실확인서에 대해 표와 체크 표시에서 검사 항목을 읽습니다. 인쇄된 서명 안내나 체크박스 항목명만으로는 값을 채운 것으로 처리하지 않습니다. 다른 배치의 양식이나 손글씨·이미지 서명은 수동 확인이 필요할 수 있습니다.

단건 검사도 제목과 기입된 값이 확인되어야 통과합니다. 필수 항목을 지정하면 항목 이름과 실제 값을 함께 확인합니다.

## 검사 결과와 공고별 기준

결과는 기본적으로 `api/document_check/check_result.json`에 저장합니다. 별도 경로는 `--output`으로 지정합니다.

```powershell
python api/document_check/cheking_document.py batch api/document_check/test_document/complete --notice-number 2026820010 --profile separate_households --birth-date 1990-01-01
```

`--notice-url`은 공고 번호 대신 사용합니다. 위 예시의 가상 생년월일은 A17의 출입국 기록대조 시작일을 계산하는 데 쓰며, 결과 JSON에 넣지 않습니다. A17의 `same_household`는 가족관계증명서 별도 제출 사유가 없는 경우로 공통 7종을 확인합니다. `separate_households`는 배우자 등본과 가족관계증명서를, `lease_deposit`는 여기에 자산보유사실확인서와 임대차계약서를 더합니다.

새 공고는 공식 안내를 대조한 뒤 `noticed_checklist.json`에 등록합니다. `common`에 공고 공통 서류, `profiles`에 신청자 유형별 변경사항을 둡니다. `add_required`로 서류를 더하고, 공식 근거가 있는 제외는 `remove_required`에 적습니다. `documents`의 `fields`에서 항목을 추가·수정하거나 `null`로 지울 수 있습니다. 유형 설정에서 공통 필수 서류를 모두 지우거나 같은 식별자로 다른 서류를 덮어쓰면 검사 기준 오류로 처리합니다.

## 추가 체크리스트 예시

공고와 신청 유형에 따라 다음 서류가 추가될 수 있습니다.

- 배우자가 신청자 등본에 등재되어 있지 않으면 배우자 등본과 가족관계증명서
- 외국인 신청자의 체류자격을 확인해야 하면 비자나 외국인등록 증빙
- 대학 복학 예정자로 신청하면 복학예정증명서
- 별도로 신고해야 하는 임차보증금이 있으면 자산보유사실확인서와 임대차계약서
- 대리인이 제출하면 위임장과 대리인 신분증

회귀 테스트는 `python -B -m unittest discover -s api/document_check/test_document`로 실행합니다.
